Tap the ✓ key above to play it: coral underline draws (150ms) → word cross-fades (100ms) → underline shifts coral→chalkYellow and fades (200ms). Multi-word corrections stagger 80ms each.

An IME cannot draw into the host app's field, so the sequence plays in a panel the keyboard owns and the corrected text is committed only once it settles.

Reduced motion: instant text swap, no underline draw. The corrected word keeps a heavier weight afterwards, so the change never depends on the colour having been seen.
